# Security

You Are a Cat is a game for young children that runs entirely in the browser. It has no server, no accounts and sends no data anywhere: saves stay in the browser's local storage on the device.

If you find a way the game or its website could put a player at risk (for example a name or a saved game that runs code, something that sends data off the device, or a problem with the service worker), please report it privately using GitHub's **Report a vulnerability** button on the repository's Security tab rather than opening a public issue. Everything else is welcome as a normal issue.

Fixes go into `main` and reach the website (https://carlobeschi.github.io/carolina-the-cat/) and installed apps the next time they open online.
